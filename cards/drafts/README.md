# UFC future-card drafts

This folder is for **unreviewed, non-executable** research-card JSON generated from actual future UFCash pre-fight feature rows by scripts/prepare_future_card.py. Missing values stay null. No synthetic or hypothetical matchups should be committed as real event evidence.

A draft cannot trigger frozen-model predictions: the inference contract requires reviewStatus REVIEWED, a genuine review timestamp, current official UFC same-bout listings and complete, nonmissing statistics.

See docs/FROZEN_FUTURE_INFERENCE_V1.md.
