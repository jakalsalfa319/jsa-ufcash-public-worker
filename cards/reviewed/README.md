# UFC future-card reviewed inputs

Only real confirmed future UFC events belong here, named YYYY-MM-DD.json. Review the source date, feature provenance, exact opponent pairings, event UTC start and any missing statistics. A user review flag is not independent proof of historical feature accuracy.

Do not store passwords, account data, private wagers, sportsbook credentials, personal bankroll details or hypothetical fixtures in this public directory. Frozen output is generated only via the manual free GitHub Actions workflow. Future inference refuses any prior event, duplicate pairing, known winner, missing feature or changed official card.

Both 21 November 2026 prediction journals are preserved separately in public/prospective and must never be overwritten. See docs/FROZEN_FUTURE_INFERENCE_V1.md.
